わんことのじかん 投稿ツール 利用規約

最終更新日: 2026年10月31日

この利用規約は、「わんことのじかん」(以下「当サイト」)が、運営者の TikTok アカウントへ動画を投稿するために運用するツール(以下「本ツール」)の利用条件を定めるものです。

1. TikTok 利用規約への同意

本ツールは TikTok の Login Kit と Content Posting API を使用しています。本ツールを利用する者は、TikTok 利用規約、Music Usage Confirmation、ブランドコンテンツを投稿する場合は Branded Content Policy に同意したものとみなされ、これに従います。TikTok による情報の扱いは TikTok プライバシーポリシー に従います。

2. 利用者

本ツールを利用できるのは、当サイトの運営者だけです。本ツールは外部に配布・販売・提供しません。

3. 利用の範囲

  • 運営者が制作し、投稿する権利を持つ動画だけを、運営者の TikTok アカウントに投稿します。
  • 他人のアカウントには使いません。動画に透かしやロゴを加えません。
  • TikTok の利用規約・コミュニティガイドライン・開発者向けの規約(Developer Terms of Service)・コンテンツ共有ガイドラインに反する使い方はしません。

4. データの扱い

本ツールが扱う情報と、その扱い方は プライバシーポリシー に定めます。

5. 規約の変更

当サイトは、必要に応じて本規約を変更することがあります。変更した場合は、このページの最終更新日を改めます。

6. お問い合わせ

本規約についてのお問い合わせは、お問い合わせページ からお送りください。
