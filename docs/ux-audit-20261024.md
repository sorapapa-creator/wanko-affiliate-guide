## 1. 再現性

### 1-1. 生成スクリプト(tools/)

- `main` には `tools/` フォルダがない(履歴を全ブランチで探しても見つからない)。カードを書き出している生成ツールは、`assets/design-fixes.css` のコメントにあるとおり別のリポジトリ(wanko-route-planner 側)にあると思われる。
- そのため **生成スクリプトの 2 回実行による比較は「未検証」**。外部 API の要不要も、このリポジトリからは判断できない。
- 同じく、指示にあった `design-system.md` と `avoid-list.md` も `main` にはない。基準は `design-fixes.css` のコメントにある「最小 12px」と、一般的な 44px のタップ領域を使った。

## 4. 指摘一覧(効果の大きい順)

効果: 大 = 多くの読者の行動や表示速度に直接効く、中 = 一部のページ・操作で効く、小 = まれ・軽微。

### 指摘 1. 絞り込みリンクから来ると、商品が何画面も下にある【効果 大・この PR で修正】

- ページ: トップの「困りごと」17 リンク、旅行準備 5 項目の 5 リンク → 主食・用品・旅行用品
- 何が起きるか: `?problem=臭い・排泄` などで絞り込みは効くが、ページ先頭に着地する。375px では最初の画面に見出しと写真しかなく、絞り込まれたカードは 2〜4 画面下。
- 数値(375px、最初に見えるカードの位置): 旅行用品 2,781px、用品 2,234px、主食 3,386〜3,496px
- スクショ: `flow-6-gear-problem-before.jpg` → `flow-6-gear-problem-after.jpg`
- 直し方: 各リンクの `href` の末尾に `#shop`(絞り込みボタンの欄)を付けた。服ページではすでに同じ書き方(`wear.html?purpose=manner#shop`)をしている。
- 修正後: 旅行用品 580px、用品 682px(どちらも最初の画面の中)、主食 1,628〜1,738px(絞り込み欄の下に条件パネルがあるため、まだ 2 画面目)

### 指摘 2. カードの中のボタン・開閉・リンクが小さい【効果 大・この PR で修正】

- ページ: 宿・おでかけ・主食・用品・服・旅行用品(全カード)
- 何が起きるか: 指で押しにくく、隣を押しやすい。
- 数値(375px、修正前): 主食・用品・服・旅行用品の「商品名と確認事項」などの開閉 高さ 20px × 2,675 件、宿の「近くの動物病院・薬局」40px × 978 件、宿の「持ち物・旅行プラン・旅の服」リンク 16px × 978 件、宿の「最新のクチコミを読む」768px で 22px × 347 件、おでかけの公式リンク 43px × 1,318 件と確認事項の開閉 24px、主食の「メーカー公式情報を確認」14px、公式サイトリンク 23px
- スクショ: `crop-goods-card-before.jpg` / `-after.jpg`、`crop-lodging-links-before.jpg` / `-after.jpg`

### 指摘 3. 宿・主食ページが重い【効果 大・オーナー判断】

- ページ: 宿(978 軒)、主食(974 件)。次いで用品・服
- 何が起きるか: 1 ページに全カードを入れているため、スマホでは開いてから操作できるまでが遅い。
- 数値: 宿 DOM 82,345 要素・HTML 4.4MB(gzip 536KB)・TBT 1.6 秒・LCP 5.4 秒・性能 45 点。主食 DOM 62,721・TBT 1.5 秒・性能 59 点。Lighthouse の DOM の目安(約 1,400)の 40〜60 倍。これは外部画像なしの値で、実機ではさらに遅い
- 直し方(案): 地域・用途ごとにページを分ける、最初は 30〜50 件だけ HTML に入れて残りは JSON から描く、カード内の長い説明を別ページに移す、など。生成ツール側の変更が必要
- 効果: 大(TBT・LCP は件数にほぼ比例するので、件数を 1/10 にできれば体感がはっきり変わる)

### 指摘 4. 宿泊前チェックの結果ページが読み込み中にずれる【効果 中・この PR で修正】

- 修正後: CLS 0.000(Lighthouse は回答なしで直接開くので、その状態での値。回答あり(2 頭・未確認 4 件)の状態は Playwright で CPU 6 倍遅延・JS 600ms 遅延にして測り、CLS 375px 0.247 → 0.071、412px 0.198 → 0.014。375px では一覧が確保した高さより 1〜3 行長くなる回答があり、少しずれが残る)
