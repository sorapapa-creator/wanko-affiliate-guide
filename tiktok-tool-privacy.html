TikTok 投稿ツールのプライバシーポリシー

最終更新日: 2026年10月31日

「わんことのじかん」(以下「当サイト」)は、当サイトの運営者が運営する TikTok アカウント(わんことのじかん @wankotono_jikan、うさぎの穴 @usaginoana.info、Made in Japan @madeinjapancraft)に、運営者が制作した動画を投稿するためのツール(以下「本ツール」)を使っています。本ツールは TikTok の Login Kit と Content Posting API を利用しています。このページでは、本ツールが扱う情報とその扱い方を説明します。

1. TikTok API の利用

本ツールは TikTok の Login Kit と Content Posting API を使用しています。本ツールの利用には TikTok 利用規約 が適用されます。TikTok による情報の扱いは TikTok プライバシーポリシー をご確認ください。

2. 本ツールが扱う情報

  • 当サイトの運営者が、投稿する TikTok アカウントでログインして許可したときに発行されるアクセストークンとリフレッシュトークン(当サイトの運営者の端末内にだけ保存します)。
  • 投稿先アカウントの表示名と、投稿できる条件(公開範囲の選択肢、コメント・デュエット・ステッチの設定、動画の長さの上限)。投稿先を確かめ、画面の選択肢を作るためにだけ読み取ります。
  • 当サイトが制作した動画ファイルと、そのタイトル・公開範囲・コメント等の許可・プロモーション内容の開示の設定。

本ツールは、運営者以外の TikTok ユーザーの情報、視聴者の情報、コメント、再生履歴などを取得・保存・利用しません。本ツールを当サイトの運営者以外が使うことはありません。

3. 情報の使い方と共有

上記の情報は、運営者の TikTok アカウントに動画を投稿するためにだけ使います。第三者に販売・提供・共有することはありません。広告や分析のために使うこともありません。

4. 保存と削除

アクセストークンは当サイトの運営者の端末内にだけ保存し、外部のサーバーには送りません。本ツールの利用をやめるときは削除します。TikTok アプリの「設定とプライバシー」→「セキュリティと権限」→「アプリの権限」から、本ツールの許可をいつでも取り消せます。取り消すとトークンは使えなくなります。

5. Cookie など

本ツールは Cookie を使いません。当サイトのウェブページでの閲覧数の計測については 運営と掲載の方針 をご覧ください。

6. お問い合わせ

本ポリシーについてのお問い合わせは、お問い合わせページ からお送りください。
