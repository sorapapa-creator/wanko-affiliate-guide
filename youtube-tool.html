わんことのじかん 投稿ツール

「わんことのじかん」が運営する YouTube チャンネル「わんことのじかん」に、当サイトで制作した動画を投稿するための社内ツールです。運営者だけが使い、外部への配布や販売はしていません。

このツールは YouTube API Services を使用しています。

プライバシーポリシー 利用規約 YouTube 利用規約 Google プライバシーポリシー

できること

  • 当サイトで制作した動画を、当サイトの YouTube チャンネルにアップロードする(タイトル・説明文・公開範囲・カテゴリの設定を含む)。
  • 動画のサムネイルを設定する。
  • 投稿先が当サイトのチャンネルであることを確かめるため、チャンネル名とチャンネル ID を読み取る。

視聴者の情報、コメント、再生回数などの分析データは取得しません。動画の削除や、他のチャンネルへの操作もしません。

使い方の流れ

  1. 運営者が、当サイトのチャンネルを管理する Google アカウントで一度だけ許可します(Google の同意画面。許可する範囲は「YouTube 動画の管理(アップロード)」と「YouTube アカウントの表示」だけです)。
  2. 運営者が、動画ファイル・タイトル・説明文を用意してツールを実行します。
  3. ツールはチャンネルを確かめてから動画をアップロードし、できた動画の URL を表示します。

許可の取り消し

許可は Google のセキュリティ設定(サードパーティのアクセス) からいつでも取り消せます。
