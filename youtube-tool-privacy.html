YouTube 投稿ツールのプライバシーポリシー

最終更新日: 2026年10月24日

「わんことのじかん」(以下「当サイト」)は、当サイトが運営する YouTube チャンネル「わんことのじかん」に、当サイトで制作した動画を投稿するための社内ツール(以下「本ツール」)を使っています。本ツールは YouTube API Services を利用しています。このページでは、本ツールが扱う情報とその扱い方を説明します。

1. YouTube API Services の利用

本ツールは YouTube API Services を使用しています。本ツールの利用には YouTube 利用規約 が適用されます。Google による情報の扱いは Google プライバシーポリシー をご確認ください。

2. 本ツールが扱う情報

  • 当サイトの運営者が、当サイトのチャンネルを管理する Google アカウントで許可したときに発行されるアクセストークン(当サイトの運営者の端末内にだけ保存します)。
  • 当サイトのチャンネル名とチャンネル ID(投稿先が正しいチャンネルかを確かめるためにだけ読み取ります)。
  • 当サイトが制作した動画ファイルと、そのタイトル・説明文・公開範囲などの設定。

本ツールは、当サイト以外の YouTube ユーザーの情報、視聴者の情報、コメント、再生履歴などを取得・保存・利用しません。本ツールを当サイトの運営者以外が使うことはありません。

3. 情報の使い方と共有

上記の情報は、当サイトのチャンネルに動画を投稿するためにだけ使います。第三者に販売・提供・共有することはありません。広告や分析のために使うこともありません。

4. 保存と削除

アクセストークンは当サイトの運営者の端末内にだけ保存し、外部のサーバーには送りません。本ツールの利用をやめるときは削除します。Google アカウントからの許可は、Google のセキュリティ設定(サードパーティのアクセス) からいつでも取り消せます。

5. Cookie など

本ツールは Cookie を使いません。当サイトのウェブページでの閲覧数の計測については 運営と掲載の方針 をご覧ください。

6. お問い合わせ

本ポリシーについてのお問い合わせは、お問い合わせページ からお送りください。
